# Automated Software Testing
## Part 1: Automated Bug Detection in Database Engines

### Building the Docker image
```
docker build -t sqlite-fuzzer .
```

### Running the container
```
docker run -it sqlite-fuzzer
```

### Available commands
The user can run the fuzzer using the following command, where the `<n>` argument is the number of queries to generate before stopping and the `<seed>` argument (optional) is a random seed for reproducibility. The statistics documented in the report were generated using the command `/usr/bin/test-db fuzz --queries 10000 --seed 42`.

```
/usr/bin/test-db fuzz --queries <n> --seed <seed> 
```

The user can run the differential test oracle on a single query using the following command. This is useful for bug reproduction after a query has been generated by the fuzzer. The command uses the `--file` argument to specify the path to a file containing a single SQL query to test.
```
/usr/bin/test-db test --file <path/to/query.sql>
```
